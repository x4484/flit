Installation Privacy Support GitHub

Flit is currently a public beta maintained through GitHub.

Get help

  • Review the installation guide.
  • Search existing issues.
  • Open a new issue for reproducible bugs or feature requests.

Include your macOS version, Mac architecture, Flit version, and clear reproduction steps. Never post OAuth files, API keys, refresh or access tokens, app-specific passwords, private email content, or diagnostic files containing personal information.

Security reports

Report vulnerabilities privately through GitHub security advisories. Do not open a public issue for a security vulnerability.

Known beta limitations

  • Gmail is the only connected provider in the first beta.
  • Google OAuth availability depends on completion and continued approval of the public consent screen.
  • New-message composition, attachments, offline SMTP outbox, and iCloud support are not yet complete.
  • Flit does not currently update itself automatically; install newer releases from GitHub.
