<section class="feature-list" aria-label="Main features">
  <article>
    <h2>Local first</h2>
    <p>Your inbox opens from SQLite before Flit touches the network.</p>
  </article>
  <article>
    <h2>Blazing fast</h2>
    <p>A native AppKit interface keeps launch, search, and triage immediate.</p>
  </article>
  <article>
    <h2>Threaded</h2>
    <p>Navigate complete Gmail conversations while downloading only the message you open.</p>
  </article>
  <article>
    <h2>Faithful email</h2>
    <p>Sender-authored layouts render in an isolated WebKit reader with active content disabled.</p>
  </article>
  <article>
    <h2>Optional AI summaries</h2>
    <p>Use your own OpenRouter key for one cached sentence. Leave it off and nothing is sent.</p>
  </article>
</section>
